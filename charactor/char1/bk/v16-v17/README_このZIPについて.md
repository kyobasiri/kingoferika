# ムーンエリカ 最終採用素材セット v17（縮尺修正版）

## 先に確認してください
このZIPは、**過去の修正履歴を大量に入れた保管庫ではなく、現時点で採用する素材だけ**をまとめたものです。

- 元のアップロード素材は **180枚**。そのうち旧8コマ×2系列の月回転16枚は、32コマ×2系列の最新版に置き換えたため入れていません。
- 対象候補素材は 559枚で、同一バイトの画像が 49件あっても連番を欠かさないため保持し、**最終採用透過WebPは 559枚**です（人物 447枚、エフェクト 112枚）。
- アニメーション定義は **52種類**です（通常/ヒット/ガード等の派生を含む）。
- `viewer/index.html` を開くと全モーションを選択・再生・コマ送りできます。

## フォルダの説明
- `sprites/00_基本原画` : 元の180枚から旧回転16枚を除いた基本原画。一般動作の基礎データを残しています。
- `sprites/01_通常技キャンセル接続` : 11、12、14、18からの追加接続姿勢。
- `sprites/02_通常技_連携中段_共通キャンセル` : 13・14・15・51と共通接続を含む最新試作。
- `sprites/03_25_突進` : 25突進必殺技。
- `sprites/04_20-23_ジヘルトリガー` : 20〜23の月操作と飛び道具。
- `sprites/05_24_対空` : 24対空必殺技。
- `sprites/06_26-27_超必殺技` : 26・27超必殺技。
- `sprites/07_52_MAX` : 最新の[20]回転始動[52]（人物と81枚の合成シーン）。
- `sprites/08_被弾反応` : 立ちくらい・しゃがみくらい・空中くらい・起き上がり・投げられ。
- `effects/` : 各技の独立した攻撃・月・光・粉塵エフェクト。
- `data/animation_manifest.json` : 最新採用フレームへの参照だけを含む動作定義。
- `data/animation_to_frames.csv` : モーションごとの実ファイルとコマ順。
- `data/asset_inventory.csv` : ファイルの寸法・ハッシュ・採用元。
- `data/identical_content.csv` : 同じ絵が複数のコマで使われている一覧。連番とファイル名を壊さないためファイルは残しています。

## なぜ758枚ではないのか
v14で数えた758枚は **旧バージョンを含む累計**です。さらにv15は[52]の旧版と新版を両方含んでいました。このv16は旧版の重複を排除しているため、枚数が少なくなります。**180枚だけではありません。**

## 現状の限界
- すべてが新規描き下ろしのポーズではなく、一部は原画を再利用・変形した試作です。
- 1024×768のキャンバスを採用している画像が多いですが、月だけのエフェクトなどサイズが異なる画像もあります。
- 描画されたエリカの身長・接地位置の完全統一は未完了。ゲーム実装では各ポーズの原点調整が必要です。
- 発生・持続・硬直、攻撃判定・無敵・キャンセル制限は試作であり、実機動作の保証はありません。
- [52]は最新版[20]始動のみです。旧[12]始動は入れていません。
- 5番は存在しないため欠番です。
